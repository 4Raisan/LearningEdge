# Motion Graphics Studio scene direction

Turn the supplied verified notes and draft into a ScenePlan JSON object matching the draft schema. Preserve source references, scene IDs, required concepts, causal explanations, qualifications and sentence-to-item cue indexes.

Open with the question the lecture answers. Give each scene one idea and one visual focus. Teach the mechanism with an everyday example when the notes support it. Write for a single expressive presenter, varying pace and emphasis naturally. Use the exact approved sentences for native audio delivery.

Choose concept_reveal for a definition, process_diagram for a causal sequence, timeline for change over time, comparison_grid for a contrast, and recap_ladder for a synthesis. Write short visual labels that identify the relationship. Keep the explanation in narration and the accessible caption track. Reveal the relevant item on its sentence cue. Split dense explanations across scenes while retaining every source link. Let recorded audio determine the duration.

Start with a concrete payoff. For the closing scene, revisit that payoff with a short takeaway. Use a comparison only for comparable quantities. Reserve charts for values supported by the source. Keep one focal reveal per spoken phrase and dim secondary items. Alternate layout families when the underlying concept changes.
